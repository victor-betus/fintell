# FINTELL
Competitive intelligence matrix via sentiment analysis & categorization with ML/DL

## Description
FINDELL is a data analytics platform that uses Natural Language Processing (NLP) and Machine Learning to analyze banking app reviews. It helps financial institutions understand customer sentiment, identify recurring issues, and uncover key factors influencing user satisfaction across competing banking applications.
